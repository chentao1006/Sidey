Sidey Privacy Policy

Privacy Policy

Last updated: March 2026

Sidey (also known as "旁白" in Chinese) is a lightweight, context-aware AI assistant for macOS. We respect your privacy and are committed to protecting any data you share with the application.

1. No Personal Data Collection

Sidey is designed with privacy at its core. The developer does not collect, store, or transmit any of your personal data, including:

  • No account registration or personal profiling.
  • No analytics, tracking, or usage telemetry.
  • No periodic "heartbeat" or identification sent to the developer's server.

2. AI Services & Data Transmission

Sidey functions as a client for AI services (such as OpenAI). When you interact with the assistant:

  • Your chat messages and system prompts are sent directly to the API provider (e.g., OpenAI) that you have configured in the settings.
  • This data transmission occurs over encrypted HTTPS connections directly from your device to the API endpoint.
  • The developer of Sidey does not act as a middleman and cannot access these communications.
  • Please refer to your API provider's privacy policy for information on how they handle your data.

3. Local & Cloud Storage

All application data is under your control:

  • API Keys & Settings: Stored securely on your local device using standard macOS storage mechanisms (UserDefaults/Keychain).
  • Prompts & Configurations: If you enable "File Sync", these are stored in a folder you choose (e.g., iCloud Drive, Dropbox). This allows you to sync data across your own devices using your own cloud storage.
  • Debug Logs: Sidey maintains a volatile local log for debugging purposes, which you can clear at any time from the settings. These logs never leave your device unless you manually export them.

4. System Permissions

To provide its core functionality, Sidey may request the following permissions:

  • Accessibility: Used solely to detect the currently active application. This allows Sidey to provide "context-aware" prompts tailored to the app you are currently using.
  • Login Item: Optional permission to start Sidey automatically when you log in to your Mac.

Most features of Sidey work entirely offline, except for the communication with your chosen AI provider.

5. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated "Last updated" date.

6. Contact

If you have any questions or concerns about this Privacy Policy, please contact us via GitHub: https://github.com/chentao1006/Sidey

Sidey 隐私政策

隐私政策

最后更新：2026年3月

Sidey（中文名“旁白”）是一款为 macOS 设计的轻量级、上下文感知 AI 助手。我们非常重视您的隐私，并致力于保护您在使用应用过程中产生的所有数据。

1. 不收集个人数据

Sidey 的设计初衷是保护隐私。开发者不会收集、存储或传输您的任何个人数据，具体包括：

  • 没有账号注册系统，不进行个人画像。
  • 没有数据统计、追踪或使用情况分析。
  • 不会向开发者的服务器发送任何身份识别信息。

2. AI 服务与数据传输

Sidey 作为 AI 服务（如 OpenAI）的客户端运行。当您与助手交互时：

  • 您的聊天信息和系统提示词将直接发送给您在设置中配置的 API 提供商（如 OpenAI）。
  • 这些数据通过加密的 HTTPS 连接直接从您的设备发送到 API 端点。
  • Sidey 的开发者不充当中间人，无法访问这些通信内容。
  • 关于 API 提供商如何处理您的数据，请参考其各自的隐私政策。

3. 本地与云端存储

所有应用数据完全由您掌控：

  • API 密钥与设置： 安全地存储在您的本地设备上，使用 macOS 标准存储机制。
  • 提示词与配置： 如果您启用了“文件同步”，这些数据将存储在您选择的文件夹中（如 iCloud Drive、Dropbox）。这允许您使用自己的云存储在不同设备间同步数据。
  • 调试日志： Sidey 会保留一份本地临时日志用于调试，您可以在设置中随时清除。这些日志除非您手动导出，否则永远不会离开您的设备。

4. 系统权限

为了实现核心功能，Sidey 可能会请求以下权限：

  • 辅助功能 (Accessibility)： 仅用于检测当前活动的应用程序。这使得 Sidey 能够根据您当前使用的应用提供“上下文感知”的提示词。
  • 登录项： 可选权限，用于在您登录 Mac 时自动启动 Sidey。

除了与您选择的 AI 提供商进行通信外，Sidey 的大部分功能都在本地离线运行。

5. 政策更新

我们可能会不时更新本隐私政策。任何更改都将发布在此页面上，并更新“最后更新”日期。

6. 联系方式

如果您对本隐私政策有任何疑问或担忧，请通过 GitHub 与我们联系： https://github.com/chentao1006/Sidey
